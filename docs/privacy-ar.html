تُستضاف الصوتيات على GitHub. يتلقى GitHub ومزوّدو توصيل الملفات عنوان الاتصال وطلبات التنزيل، وقد يحتفظون ببيانات تقنية وفق سياسة خصوصيتهم. توضح سياسة GitHub إمكانية استنتاج الموقع التقريبي من عنوان IP ومعالجة معلومات الطلب والجهاز وإحصاءات الخدمة والأمان وتشخيص المشكلات. قد ترتبط هذه السجلات التقنية بشبكتك أو جهازك؛ ولا نضمن إخفاء مزود الاستضافة لهويتك قبل حفظها. لذلك يتضمن إفصاح App Store، احتياطًا، الموقع التقريبي وبيانات الاستخدام والتشخيص المتعلقة بالتنزيل. لا يطلب التطبيق موقع GPS ولا يرسل معرّفًا إعلانيًا. لا يحتاج المستخدم إلى حساب GitHub، ولا تُرفع ملاحظاته أو تسجيلاته أو علاماته معهم.
