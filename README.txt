Quran Reader — Minshawi recitation audio

This repository distributes optional audio assets for Quran Reader.
The release contains 114 surah ZIP packages and SHA-256 integrity manifests.
The 6,236 supplied MP3 verse files are preserved without re-encoding.
Filenames use SSSAAA.mp3 (three-digit surah and verse); verse 000 is excluded.

Application source code remains in a separate private repository.
Quran page images, user notes, highlights, bookmarks and credentials are not included.

Download packages from Releases: minshawi-v1.
